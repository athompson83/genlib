# Repository dependency diagram

Run `node tools/repo-map.mjs build`, `node tools/repo-ast.mjs build`, then `node tools/repo-diagram.mjs`. The diagram now shows directory groups and counts of **resolved cross-group imports**, rather than only a folder listing. The output is a Mermaid `.mmd` file and is regenerated by GitHub Actions for every push/PR, along with the commit-specific JSON index.

The diagram prefers the AST graph. It falls back to the relative-import graph only when the AST artifact is absent, **not** when it is stale or invalid. Each source must match HEAD. Edges are static import relationships, not runtime calls, execution traces, ownership boundaries or proof of test coverage.

The generator never uploads source to GitDiagram. Large repositories may need grouping thresholds and more accurate path-alias resolution before this view is suitable for architecture decisions.
